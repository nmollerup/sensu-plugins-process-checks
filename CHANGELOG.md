## [Unreleased]

### Added
- Initial Go implementation of sensu-plugins-process-checks
- check-process: Monitor processes with various filters
- check-cmd: Run commands and check output/status
- check-process-restart: Detect process restarts
- check-threads-count: Monitor thread counts
- metrics-per-process: Per-process statistics
- metrics-process-status: Process status counts
- metrics-process-uptime: Process uptime tracking
- metrics-processes-threads-count: Thread count metrics
- Cross-platform builds for Linux (amd64, 386, arm64, armv7)
- Sensu Bonsai asset configuration
